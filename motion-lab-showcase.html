01解决的痛点

做前端动效时，每个人都掉进过同样的坑。

🧩

找不到合适的动效

CodePen、Cuberto、Awwwards、YouTube 散落各处，没有统一检索；想"加个打字机"要在 5 个网站切换。

⚙️

找到却不可调参

复制到项目里发现颜色 / 速度 / 触发时机和图不一样，又得自己改源码试，浪费时间。

🤖

AI 不会做动效

让 AI 写"按钮波纹"它会输出很基础的方案；每次都重描述需求，没有项目级动效库可调用。

📦

无法沉淀资产

做完一个项目的动效无法复用，下次又得重新找；团队成员各自维护，无法共享。

023 分钟接入 AI

从打开网站到 AI 输出可用代码，只需 4 步。

1

下载 SKILL.md

点击下载按钮，存到 Agent 项目的 .trae/skills/ 或 .claude/skills/ 目录。

2

自然语言提问

告诉 Agent 你想要的动效 — "按钮波纹"、"粒子背景"、"打字机"等，160 个动效秒级匹配。

3

拿到 3 段代码

Agent 输出 HTML + CSS + JS 三段源码，附可调参数表，参数化 --duration 等 CSS 变量。

4

复制即用

粘贴到项目，调参数即可生效；如需更深定制，访问官网 /lab/<id> 在线实时调参。
